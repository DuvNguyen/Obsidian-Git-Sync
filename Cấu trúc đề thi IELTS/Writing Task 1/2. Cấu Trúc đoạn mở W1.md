# 1. Cấu trúc đoạn intro:
- 1 Câu paraphrase đề bài 
- Sau đó là 1 đến 2 câu overview mô tả:
	- Thay đổi cao nhất - highest changes
	- Thay đổi thấp nhất - lowest changes
	- Thay đổi nổi bật nhất - most dramatic changes
	- Xu hướng tăng/giảm (có thể so sánh)
## 1.1. Paraphrase – kỹ năng bắt buộc:

### A. Đổi từ vựng:

- shows → illustrates / presents / depicts
- changes → trends / variations
- number → figure / amount
- spending on/for (Tiền dành để mua cái gì) 
	-> expenditure on/for 
- at the age of + number 
	-> the people aged + number
	-> the + number + age group
### B.  Đổi cấu trúc:
#### Số lượng
- the percentage of: 
	-> the proportion of + N 
	-> the figure for + N
	-> the number of + N 
#### Khoảng thời gian:
* From A to B.
	-> between A and B
	-> over the period of + number + years
## 1.2. Từ dẫn vào overview:

- Overall
- In general, generally
- It is a clear (hoặc evident) that  S + V
